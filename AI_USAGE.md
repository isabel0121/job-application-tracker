# AI Usage Documentation

## 1. AI Tool Used

**ChatGPT**

ChatGPT was used as a supporting tool during the development of the Job Application Tracker. It helped generate ideas, explain programming concepts, troubleshoot errors, and improve existing code.

## 2. How AI Was Used

- **Project planning:** Getting ideas for application features, pages, and organization.
- **Database:** Understanding MySQL tables, relationships, primary keys, and foreign keys.
- **Backend:** Getting help with Python, Flask routes, database connections, and CRUD operations.
- **Frontend:** Improving HTML templates, forms, navigation, and CSS styling.
- **Job Match:** Developing the logic to compare user skills with job requirements and calculate matching percentages.

## 3. Examples of Prompts Used

- "Help me organize the pages and features of my Job Application Tracker."
- "Can you review my Python code and help me find the error?"
- "Why am I getting this MySQL insertion error?"
- "How can I connect Flask to my MySQL database?"

## 4. Problems and Solutions

During development, ChatGPT helped troubleshoot several issues.

- **MySQL errors:** Helped identify missing required fields when inserting contacts.
- **Python errors:** Helped review code and identify problems in database functions and Flask routes.
- **Job Match:** Helped develop the skill-comparison logic and rank jobs by matching percentage.
- **Database differences:** Some suggested code needed adjustments to match the actual database column names.

## 5. Testing and Verification

After making changes, I tested the application to verify that the features worked correctly. Testing included viewing records, creating and updating entries, checking database information, and testing Job Match with different skills.

## 6. Limitations and Lessons Learned

Not every AI suggestion worked immediately. Some code needed to be modified to fit the existing database structure. This showed the importance of reviewing, understanding, and testing AI-generated suggestions instead of copying them without verification.

Through this project, I improved my understanding of Python, Flask, MySQL, database relationships, CRUD operations, and full-stack application development.

## 7. Final Reflection

ChatGPT helped make development more efficient by providing ideas, explanations, and debugging assistance. However, the suggestions had to be reviewed, adapted, and tested to ensure they met the project requirements.
